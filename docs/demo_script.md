# Five-minute demo

1. Start the backend and show `read_only_mode=true` and
   `payload_decrypted=false` in health output.
2. Generate seeded `mixed_enterprise` replay and show benign cloud sync stays
   contextual rather than being blacklisted.
3. Replay horizontal reconnaissance and open its fan-out evidence.
4. Replay DGA-like DNS, beaconing, encrypted metadata, and exfiltration-like
   scenarios; state what is observed and what is inferred.
5. Show a legitimate-service chain only after independent signals correlate.
6. Open the explanation panel, then show measured benchmark files and known
   limitations. Never present synthetic metrics as production accuracy.
