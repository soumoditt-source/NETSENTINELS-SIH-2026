# Limitations

NetSentinel is a metadata-only early-warning prototype. It cannot identify
malware with certainty from one flow, decrypt payloads, send probes, block
traffic, or provide universal performance guarantees. Legitimate scanners,
backups, monitoring agents, updates, CDNs, and cloud services can resemble
suspicious behavior. Dataset shift, label quality, capture grouping, missing
fields, and encrypted metadata visibility affect recall and precision.
